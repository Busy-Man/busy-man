### 1. 빌드 / 소스코드

- 심사자가 직접 플레이 가능해야 한다 (별도 유료 라이선스·계정 가입·API 키 입력 불필요)
- **PC 실행 파일(.exe 등) 제출 불가** — 보안상 이유. 웹 빌드 또는 모바일 앱만 허용
- 전체 소스 코드를 동일 저장소에 포함하고 **커밋 기록을 유지**해야 한다
  → `AGENTS.md` §5의 squash·force-push 금지는 이 요건에서 온 것이다
- 저장소는 public 권장. 부득이 private이면 심사 계정 초대: `dl_gameai_reviewer@nhn.com`
  - 현재 저장소: `github.com/Busy-Man/busy-man`

### 2. 플레이 동영상

- 실제 게임 플레이 화면 그대로. AI 조작·합성, 타인 영상 도용 불가
- 공개 또는 일부 공개(링크 공유)로 업로드

## 제한사항

- 타인 저작물·아이디어 무단 도용 적발 시 선발 취소. 모든 책임은 제출자 본인 부담
- 외부 에셋(이미지·사운드 등) 사용 시 **출처·라이선스를 AI 활용 기술 문서에 반드시 명시**
- **AI 도구 사용은 허용·권장** — 단 사용 도구와 활용 내역을 반드시 기재
- 제출 링크(GitHub / YouTube)는 심사 종료 시점까지 접근 가능하게 유지
- 유료 API 사용료는 참가자 본인 부담

## 제출 직전 최종 점검 — 로그아웃 상태에서 확인

- [ ] GitHub 저장소 public (private이면 `dl_gameai_reviewer@nhn.com` 초대)
- [ ] Pages 링크가 시크릿 창에서 열리고 바로 플레이됨
- [ ] 결제·계정 가입·API 키 입력 없이 플레이 가능
- [ ] YouTube 영상이 "일부 공개" 이상이고 링크로 재생됨
- [ ] 커밋 기록이 남아 있음 (squash / force-push 하지 않았음)
- [ ] 외부 에셋 출처·라이선스가 문서 4번에 전부 기재됨

이 문서의 이전 판에는 "아직 결정되지 않은 것" 목록이 있었다. 아래대로 모두 닫혔다.

| 항목 | 결정 |
|---|---|
| 장르·컨셉 | 출근길 주행 + 고객사 문자 응답. 전방과 폰을 번갈아 보게 만드는 것이 코어 |
| 플랫폼 | **웹** — GitHub Pages (제출 요건상 가장 간단) |
| 기술 스택 | 번들러 없음. HTML + ES 모듈 + Canvas |
| 렌더러 | **미결** — Canvas 2D vs three.js. `renderer-comparison.html` 참조. 8/6 이후 변경 금지 |
| AI 활용 방식 | 게임 내 런타임 AI 없음. **개발 과정 전반에 AI 활용** + 대화·질문 콘텐츠 AI 생성 |
| 팀 구성 | 2인. 구현은 **A=맵·주행, B=대화·질문 이벤트**, 대외 산출물은 위 표대로. 분담 기준은 난이도가 아니라 파일 (`AGENTS.md` §1) |
| 일정 | 실질 개발 8/3~8/6 (3.5일), 8/7 동결, 8/8 영상, 8/9 인계, 8/10 제출. **버퍼 0** |

컨셉이 확정되어 **이 저장소 하나가 곧 출품작**이다.
