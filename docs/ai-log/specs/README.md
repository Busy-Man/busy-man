# ai-log/specs/

**AI가 만든 계획·명세 문서를 그대로 보존하는 곳.** 파일명은 `YYYY-MM-DD-<주제>.md`.

## 왜 남기는가

코드는 커밋에 남지만 **"왜 그렇게 만들기로 했는가"는 남지 않는다.**
그 판단이 담긴 것이 이 문서들이고, 제출물 4번에서 두 절의 재료가 된다.

- **AI에게 준 주요 지시 사항** — 명세에 남은 질의와 결정 과정
- **AI 산출물의 검증** — 무엇을 채택하고 무엇을 잘라냈는지

에이전트 도구가 쓰는 작업 디렉터리(`.omc/` 등)는 `.gitignore` 대상이라
**거기 두면 팀원이 볼 수 없고 정리하는 순간 사라진다.** 그래서 저장소로 옮겨 커밋한다.

## 무엇을 남기는가

- deep-interview 명세, 계획서, 설계 판단 기록
- 채택되지 않은 안도 남긴다. 잘라낸 이유가 곧 검증 기록이다

## 손대지 않는다

생성 당시 그대로 둔다. 나중에 판단이 바뀌면 이 파일을 고치지 말고
`../ai_usage_log.md`의 해당 엔트리와 §3 폐기 표에 적는다.
그래야 "그때는 그렇게 판단했다"가 보존된다.
