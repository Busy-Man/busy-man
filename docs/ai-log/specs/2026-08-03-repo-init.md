## Goal

`busy-man` 저장소를, 8/3 오전 팀 합의 직후 A와 B가 각자 AI 에이전트를 붙여 곧바로 병렬 작업에 들어갈 수 있는 상태로 만든다. 산출물은 **구현 코드가 아니라 경계와 규약**이다. 구체적으로:

1. 저장소 밖에 있어 팀원이 볼 수 없던 문서(`CLAUDE.md`, `ai_log_guidelines.md`)를 저장소 안으로 들여오고 낡은 내용을 최신화한다.
2. `docs/team-plan.html`이 문서로만 합의한 파일 소유 경계를 **실제 파일**로 못박는다.
3. 제출물 4번(AI 활용 기술 문서)의 재료가 사후 복원 불가능하다는 점을 인정하고, **프롬프트 원문 포획**을 자동화한다.
4. GitHub Pages 하위 경로에서 ES 모듈 상대경로가 정상 해석됨을 오늘 밤에 증명해, 8/5 병합일에 처음 마주치는 일이 없게 한다.
