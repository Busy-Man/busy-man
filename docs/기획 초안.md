## 질문 이벤트

- 분량: 6~10개 (조절 필요)

- 객관식으로. 보기는 3개
- 실시간 vs. 모달
- 실시간: 그냥 실시간으로. 계속 이동하기 때문에, 네비를 봐야하고 사람을 피해야 해서, 정신은 없지만 보기는 좀 쉽고, 다른 휴대폰을 볼 수 있음
- 모달 방식: 고객사 질문이 오면, 휴대폰 UI는 띄우지 않고, 알림만 띄움 -> 그 후, 화면 중앙에 모달창이 뜸 (이 때, 모달을 제외하고 모든 UI와는 상호작용 못 함 + 시간이 멈춤). -> 문제 보기(지문)가 어렵다. (기억력 테스트 느낌?)

### 질문(문제) 보기

if 스크랩이 있으면, 보기 3개 중에 1개는 스크랩 리스트를 보여주고, 스크랩 중 하나를 고를 수 있게

else 스크랩이 없으면, 그냥 보기 3개를 띄운다.

보기 문체도 대화체로. 이유: 스크랩이 원문이니까.


### 대화 내용

지나간 내용 다시 못 보게 vs. 스크롤로 다시 볼 수 있게

- 치팅 페이퍼: 대화를 누른다? 화면에 메모장 존재 -> 최대 5개 북마크처럼 메모 가능. 정답을 맞히면 삭제 가능 (즉, 다른 문자 찜 가능).
- 메모장 대신: 찜을 하면, 찜한 문자에 대한 질문이 나왔을 때, 원문을 같이 보여준다.


### 대화 (문자)

- 사람: 같은 색
- 알림: 랜덤. 사람이랑 같은 색도 있고 다른 색도
- 속도: 일단 프로토타입대로

테스트: 잘 헷갈린다면 성공
