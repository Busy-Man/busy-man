## 질문 폰 (`src/quiz.js`)

질문 이벤트가 발동하면 뜬다. 뜨는 동안 **주행·입력·시간이 전부 멈춘다.**

### 등장

**화면 바깥에서 위로 올라온다.** 페이드인이 아니다 —
문자가 도착해서 폰을 들어 올리는 동작으로 읽혀야 한다.

### 구성 — 위에서 아래로

```
┌─────────────────────────────┐
│ 03:20            [카운트다운] │  ← 상태바
├─────────────────────────────┤
│ ▎질문 (문제)                 │  ← 수신 말풍선
│                             │
├─────────────────────────────┤
│  (       입력란       )  ↵   │  ← 장식
├─────────────────────────────┤
│ ▎ 보기 1                     │
│ ▎ 보기 2                     │  ← 답장 후보
│ ▎ 보기 3                     │
└─────────────────────────────┘
```

| 요소 | 내용 | 비고 |
|---|---|---|
| 좌측 상단 | **시계** | 연출용. 스테이지 남은 시간이 아니다 |
| 우측 상단 | **카운트다운 배지** | **10초** 답변 제한 |
| 본문 | 질문 | **수신 문자 말풍선**으로 띄운다. 문제 상자가 아니다 |
| 입력란 | 비어 있는 입력창 + 엔터 화살표 | **장식.** 실제로 타이핑하지 않는다 |
| 하단 | **보기 3개** | 답장 후보처럼 보이게 둔다 |

### 입력

**마우스 클릭.** 목업 이미지의 보기에 `1. 2. 3.` 번호가 붙어 있지만
그건 생성 과정에서 생긴 것이고 **숫자키 단축키가 아니다.**

키 입력이 아니므로 `main.js`(**A**)의 입력 라우팅이 보기 선택을 중계할 일이 없다.
`state.quizOpen`은 원래 의미 그대로 **"A는 이동·입력을 멈춘다"**이다 (`AGENTS.md` §2).

### 판정

- 정답 → 게이지 +
- **오답과 타임아웃은 같은 벌** — **감속 / 게이지 감소 2종 중 랜덤** (`AGENTS.md` §3).
  8/5에 되살렸다. 그래서 `state.gauge`는 정답 전용이 아니게 됐다 — 오답에도 B가 쓴다
- 어느 쪽이 걸렸는지 **모달에 결과만 적는다.** 룰렛·카드 연출은 아직 보류다
- 랜덤 비율·감속량·게이지 감소량은 정해지지 않았다. 찍기 밸런스와 함께 8/6에 본다
  → [`balance-todo.md`](./balance-todo.md)

## 대화 스트림 폰 (`src/phone.js`)

space를 **누르고 있는 동안**만 보인다 (토글 아님). 고개를 내리는 동작이다.

- 사람이 보낸 문자는 **같은 색**
- 알림은 **랜덤** — 사람과 같은 색도 있고 다른 색도 있다.
  헷갈리게 만드는 것이 목적이다. 잘 헷갈리면 성공이다
- 흐르는 속도는 프로토타입대로
- **지나간 내용은 다시 못 본다.** 스크롤이 없다
- 스크랩·북마크는 이번 스코프에 **없다** (`AGENTS.md` §3 — 폐기가 아니라 보류)

**질문 모달이 떠 있는 동안에는 열 수 없다.** 모달 중에는 모든 UI 상호작용이 막히므로
space도 먹지 않는다. 즉 질문에 답할 때 **대화를 되짚어볼 수 없고**, 기억에 의존한다.

## 아직 정하지 않은 것

- 폰 두 대의 실제 픽셀 크기와 화면 점유율
- 질문 발동 알림의 형태 (소리 / 화면 흔들림 / 폰 아이콘)
- 상태바 시계가 게임 내 시각을 따라가는지, 고정 더미인지
