03역할 분담

둘 다 AI로 코드를 뽑을 예정이므로, 분담 기준은 난이도가 아니라 파일입니다. 같은 파일을 둘이 AI에게 던지면 서로의 코드를 덮어씁니다. 경계선은 “화면 위 / 폰 안”입니다.

A

주행 레이어 · 대외 산출물

  • 복도 렌더, 자동 전진, 좌우 이동, 3통로 갈림길 판정 world.js
  • 보행자 충돌 감속, 게이지 소비 가속 world.js
  • 게임 루프, 입력 라우팅, 제한시간, HUD, 결과 화면 main.js
  • docs/ai_usage_log.md 매일 기록
  • 데모 영상 촬영 · 편집 · 업로드
  • 문서 3 · 4 · 5번 취합
B

폰 레이어 · 콘텐츠 · 배포 · 제출

  • 폰 UI, 대화 스트림 (사람·알림 색 구분, 흐름 속도) phone.js
  • 질문 모달, 보기 3개, 정오답 처리, 감속 패널티 quiz.js
  • 대화 로그·질문·정답 근거·함정 단서 AI 생성 → 정적 JSON content/day1.json
  • 저장소 + GitHub Pages 배포, 모바일 브라우저 확인
  • 문서 3 · 4 · 5번 기술 파트 초안
  • 8/10 최종 제출

A의 원래 할 일 목록에서 에셋 제작은 삭제합니다. A의 구현 지분은 8/3~8/6에 몰아넣고, 8/7부터 A는 코드에서 손을 뗍니다.

접점은 네 개뿐

이 네 개만 state.js에 두고 나머지는 서로 건드리지 않습니다. 8/3 오전에 실제 파일로 먼저 커밋하세요. 문서로 합의하면 지켜지지 않지만, 파일이 이미 있으면 둘 다 그걸 import 합니다.

state.speedMul   // B가 오답 감속으로 낮춤 → A가 주행 속도에 곱함
state.gauge      // B가 정답 시 + → A가 Shift로 소비
state.quizOpen   // B가 모달 뜨면 true → A는 이동·입력 정지
onGate(cb)       // B가 등록 → A가 갈림길에서 fireGate 로 발화
